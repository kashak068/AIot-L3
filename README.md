# Taiwan Weather Forecast ⛅ 台灣氣溫觀測與預報系統

本專案使用台灣交通部中央氣象署（CWA）開放資料 API，取得全台各地氣候與氣溫資訊，透過 Python 模組進行 JSON 解析與結構化清理，持久化儲存至 SQLite 資料庫，並運用 Streamlit 構建兼具互動性與現代化視覺體驗的 Web 儀表板。

---

## 專案目的與核心理念

本專案致力於打造一個開源、輕量且易於擴展的**台灣即時氣象與氣溫分析儀表板**。

主要目標包含：
- **完整數據管線實踐**：展示從「官方資料擷取（API）」、「資料清理與結構化（ETL）」、「本地持久化（SQLite）」到「資料視覺化展示（Streamlit）」的現代 Python 數據應用全流程。
- **解決資訊分散問題**：將官方複雜且多層次巢狀的氣象資料，轉化為直覺明瞭的關鍵指標與互動圖表。
- **快取保護與離線查詢**：建立資料庫快取機制，降低對氣象署伺服器的頻繁呼叫，並提供歷史氣象資料累積與比對能力。

---

## 台灣天氣資料的重要性

台灣地處亞熱帶與熱帶交界，島內中央山脈縱貫南北，造就了多樣且複雜的微氣候（Microclimate）：
1. **氣候多變性**：受季風、地形雨、午後熱對流與颱風系統交替影響，南北氣候、山區與平地之氣溫及降雨差異極大。
2. **民生日常決策**：氣溫波動直接關聯民眾穿著、戶外活動安排、交通安全及防暑防寒準備。
3. **產業與防災價值**：農業栽種防霜熱害、水資源調節、電力調度尖峰預估，乃至颱風豪雨災害防制，均高度仰賴高精度、高時效性的天氣資訊。

### 1. CWA API 的角色（資料權威源）
- **核心來源**：交通部中央氣象署開放資料平台（Central Weather Administration OpenData API）為台灣氣象觀測與預報的國家級官方權威來源。
- **任務使命**：提供全台各縣市自動測站觀測資料（O-A0003-001）與 36 小時天氣預報（F-C0032-001）等標準 RESTful JSON 接口，確保數據準確可靠。

### 2. Python 的角色（系統核心驅動引擎）
- **全鏈路中樞**：貫穿專案全流程，負責協調 API 呼叫、數據清洗、資料庫交易及展示邏輯。
- **任務使命**：
  - 使用 `requests` 套件安全傳遞授權金鑰並獲取 API 回應。
  - 將原始多層巢狀、混合格式的 JSON 數據解構為 Python 字典與 Pandas DataFrame 結構。
  - 處理缺失值填補、日期時間格式轉換（ISO 8601）、數值型別轉型。

### 3. SQLite 的角色（輕量資料快取與歷史保存）
- **零配置關聯資料庫**：內建於 Python 標準函式庫，以單一檔案方式存放在 `data/` 目錄。
- **任務使命**：
  - **請求節流與快取（Caching）**：保存最近一次抓取的資料，避免使用者重複刷新造成 API 額度超限或延遲。
  - **歷史記錄存檔**：持續累積氣象與氣溫數據，為日後趨勢回溯提供依據。
  - **結構化查詢**：透過標準 SQL 語法進行縣市、測站與時間區段的快速索引檢索。

### 4. Streamlit 的角色（敏捷互動 Web 展示）
- **純 Python Web 框架**：無需編寫複雜的 HTML/CSS/JavaScript，專注於數據表現。
- **任務使命**：
  - 打造現代化視覺介面，提供縣市下拉選單、日期範圍挑選器與重新整理按鈕。
  - 呈現直觀的關鍵氣象 Metric 卡片（如當前最高溫、最低溫、降雨機率）。
  - 將氣溫數據即時繪製為多時段變動趨勢圖表。

## 最終 Web App 功能規劃

1. **全台即時氣候大盤看板**：
   - 即時顯示今日全台「最高溫測站」、「最低溫測站」與「全島平均氣溫」。
   - 天氣概況速覽卡片（舒適度、降雨機率、天氣現象圖示）。
2. **多維度篩選與切換**：
   - 提供 22 個縣市快速下拉切換。
   - 支援各行政區/鄉鎮專屬觀測測站細節檢視。
3. **氣溫變化趨勢圖表**：
   - 未來 24～36 小時高低溫曲線變化折線圖。
   - 舒適度及溫差區間動態標註。
4. **資料同步與狀態管理**：
   - 標示資料最後更新時間戳記（Last Updated Timestamp）。
   - 提供「手動更新資料」按鈕，觸發後台檢查並同步最新 CWA API 資料。

## 專案目錄結構

```text
Taiwan-Weather-Forecast/
├── .gitignore          # Git 版控忽略規則（虛擬環境、敏感金鑰、SQLite 資料庫等）
├── README.md           # 專案說明與開發指引文件
├── requirements.txt    # 專案相依套件清單

├── data/               # 資料儲存目錄（存放 SQLite .db 檔案或快取資料）
│   └── .gitkeep
├── src/                # 核心業務邏輯原始碼（API 串接、資料解析、資料庫操作等模組）
│   └── __init__.py
└── tests/              # 單元測試與整合測試目錄
    ├── __init__.py
    └── test_basic.py
```

### 資料夾與主要檔案用途說明

| 目錄 / 檔案 | 類型 | 用途說明 |
| :--- | :--- | :--- |
| `src/` | 目錄 | **核心程式庫**。放置應用程式的核心邏輯模組，例如 CWA API 請求客戶端、JSON 解析轉換邏輯、SQLite 資料表操作等，與展示層（UI）解耦。 |
| `data/` | 目錄 | **本機資料儲存區**。用於儲存本機產生的 SQLite 資料庫檔案（如 `weather.db`）或離線快取的 JSON 備份檔（已由 `.gitignore` 排除版控）。 |
| `tests/` | 目錄 | **測試目錄**。存放 `pytest` 或 `unittest` 測試案例，用於驗證 API 格式、資料轉換與資料庫讀寫正確性。 |
| `app.py` | 檔案 | **Streamlit 應用程式進入點**。負責建立互動式 Web UI、調用 `src/` 模組讀取資料庫並繪製圖表。 |
| `requirements.txt` | 檔案 | **相依套件定義檔**。列出專案執行所需的 Python 第三方套件與版本規格（如 `requests`, `streamlit`, `pandas`）。 |
| `.gitignore` | 檔案 | **Git 忽略清單**。防止本機環境檔、快取、金鑰與大型資料庫提交至 Git 倉庫。 |
| `README.md` | 檔案 | **專案文件**。提供專案架構概覽、技術角色說明、安裝環境與啟動說明。 |

## 快速開始與環境建置

### 1. 建立並啟動虛擬環境

**Windows (PowerShell)**:
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**macOS / Linux**:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. 安裝相依套件

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. 設定氣象署 API 金鑰

在專案根目錄下建立 `.env` 檔案，填入向中央氣象署申請之授權碼：
```env
CWA_API_KEY=YOUR_CWA_API_KEY_HERE
```

### 4. 啟動 Streamlit 應用程式

```bash
streamlit run app.py
```
